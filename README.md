# 施工日誌產生器 Construction Log Generator

把「公共工程施工日誌」從 PCCES 匯出的工項清單，自動產生成一份完整的 Excel 施工管理活頁簿：
日資料庫（逐日填報）、預定進度（S 曲線）、甘特圖、施工日報（依公共工程委員會附表四官方格式）、
工程進度儀表板、以及支援契約變更（設計變更）快速套用。

## 線上 Demo

`docs/index.html` 是完全獨立、不需要安裝任何東西的瀏覽器版本——用 [Pyodide](https://pyodide.org/)
（把 CPython 編譯成 WebAssembly）在瀏覽器裡直接執行跟 `python/` 資料夾下完全相同的 Python 邏輯，
不會把任何檔案上傳到任何伺服器，所有運算都在使用者自己的瀏覽器裡完成。

把這個 repo 的 **Settings → Pages → Source 設成「main branch / docs 資料夾」**，就會得到一個
`https://<你的帳號>.github.io/<repo名稱>/` 的線上示範連結，可以直接拖檔案進去試用，不需要另外架
伺服器或寫後端。

## 功能

- **日資料庫**：把 PCCES 工項清單自動排成「一列一天」的填報表，含材料/工別/機具主檔。
- **預定進度**：任務清單（起訖日+權重）自動算出逐日累計預定進度 % 與 S 曲線。
- **甘特圖**：橫向長條甘特圖 + S 曲線折線圖。
- **施工日報**：完全依公共工程委員會《公共工程施工品質管理作業要點》附表四官方格式重建，
  含超前/落後估算、工地安全檢查勾選欄位、大項/中項進度統計（可摺疊）、列印邊界與重複表頭設定。
- **儀表板**：KPI 總覽、大項/中項/工項進度總覽，自動標示可能落後的工項。
- **契約變更快速套用**：把「變更後」的新工項清單套用到已經填了逐日資料的舊活頁簿上，保留已填
  資料、不遺失歷史紀錄，也支援工期展延（輸入展延後完工日期，自動反推天數）。
- 同時支援標準 PCCES「詳細價目表」格式，以及機關/廠商常見的「變更設計比較表」格式
  （同一列並列原契約/變更後兩組數量單價）。

## 本機安裝與使用（CLI版）

1. 安裝 Python 3.9 以上版本（<https://www.python.org/downloads/>），安裝時記得勾選
   「Add python.exe to PATH」。
2. 安裝套件：

   ```
   cd python
   pip install -r ../requirements.txt
   ```

3. 執行：

   ```
   python build_construction_log.py "你的PCCES匯出檔.xls"
   ```

常用參數（都有預設值，不給也能跑）：

| 參數 | 用途 | 預設 |
|---|---|---|
| `--sheet 分頁名稱` | 手動指定要讀哪個分頁 | 自動偵測含「項次/單位/數量/單價」表頭的分頁 |
| `--start-date 2026-09-01` | 開工日期 | 今天（事後也可直接在Excel B2改） |
| `--days 200` | 日資料庫要建幾天份 | 200天 |
| `--end-date 2026-12-31` | 展延後完工日期（優先於`--days`，自動反推天數） | 無 |
| `--agency` / `--project-name` / `--location` / `--proj-code` | 主辦機關／工程名稱／地點／編號（PCCES讀不到時手動覆寫） | 自動從檔案抓 |
| `--n-mat` / `--n-labor` / `--n-mach` | 材料／工別／機具主檔筆數上限 | 12 / 8 / 8 |
| `--out 檔名.xlsx` | 輸出檔名 | 用工程名稱自動命名 |
| `--apply-change-to 舊檔案.xlsx` | 套用契約變更：把新PCCES清單套到這份已填資料的舊檔案上 | 無（不指定就是產生全新日誌） |

範例：

```
python build_construction_log.py "案A_標價清單.xlsx" --start-date 2026-09-01 --out 案A_施工日誌.xlsx
```

## 免安裝版（GUI）

直接用瀏覽器打開 `docs/index.html`（或用上方 Demo 連結），把 PCCES 檔案拖進頁面即可，
不需要安裝 Python 或任何套件。

## 已知限制

- 「儀表板」判斷工項是否落後，是拿『全案整體』一條 S 曲線當比較基準，不是每個工項各自
  獨立的排程；若某工項規劃在工期後段才開始，可能被誤判為落後，需人工複核。
- 「套用契約變更」用「工項名稱逐字完全相同」判斷新舊是否為同一項：純改名會被當成
  「刪除+新增」；若同一份契約清單裡有兩個以上工項名稱完全相同，也可能造成逐日資料誤植，
  程式會印出明確警告，需人工核對。
- 尚未包含「估驗計價」自動產生工具、技術士簽章表、工地職業安全衛生施工前檢查紀錄表（附表四
  的另外兩張附表）。
